# Stampa

App per il telefono: scegli una bolletta (PDF) o una foto e stampala con un tocco.

- Il file resta sul telefono: viene preparato nell'app e passato alla stampa di Android (plugin della stampante già installato).
- Installabile: da Chrome, menu ⋮ → "Aggiungi a schermata Home".
- Pulsante "Controlla" apre la pagina della stampante per vedere l'inchiostro (solo dal Wi-Fi di casa).

Aggiornamenti: modificare i file e aumentare `CACHE` in `sw.js`.
